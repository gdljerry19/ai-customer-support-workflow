Example Case: Customer Request Status

Customer Request

"I submitted my request three days ago and haven't received an update. Can you tell me what's happening?"

Step 1: Capture and Normalize

Request: Customer wants an update on a previously submitted request.

Missing information: Request or case number and current status.

Step 2: Classify

Category: Request status

Urgency: Normal

Step 3: Check Available Information

The AI should review the available case or request information before preparing a response.

Important: The AI must not assume that a request was completed or create a status that is not supported by available information.

Step 4: AI Recommendation

Recommended action: Verify the current request status and provide the customer with an accurate update.

Human review: Required if the available information is incomplete, contradictory, or unavailable.

Step 5: Draft Response

Thank you for reaching out. I understand you're looking for an update on your request. I'll review the current status and make sure you receive the most accurate information. If anything further is needed from you, I'll let you know.

Step 6: Documentation

Action taken: Request status identified and verification recommended.

Follow-up: Create a follow-up task if additional investigation is required.

Result

The workflow helps the support representative quickly understand the request, identify missing information, avoid making assumptions, and determine when human involvement is needed.
